# Results

Save the outputs of `notebooks/capstone_train_and_evaluate.ipynb` here after running it in Colab:

- `training_curves.png`: loss and accuracy per epoch
- `base_vs_finetuned.csv`: side-by-side outputs on the test prompts
- `automatic_checks.csv`: format, length and overlap scores per test example
- `human_eval_sheet.csv` and `human_eval_key.csv`: blind teacher rating sheet and the key (which model wrote each answer)
- `run_config.json`: the exact settings used

The notebook downloads a zip of these at the end; unzip it into this folder.

Then copy the key numbers and three example outputs into `PROJECT_REPORT.md` section 7 and
`MODEL_CARD.md`. Do not edit results by hand.
